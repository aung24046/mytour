✓ มีครบแล้วในต้นแบบนี้

  • 5 โหมด — ทีละคน / หลายคน / แบ่งกลุ่ม / จับคู่ / ลำดับคิว
  • แหล่งรายชื่อ 2 ทาง + กรอง 5 แบบ + ติ๊กตัดรายคน
  • รางวัลหลายชิ้น สุ่มไล่ลำดับ นับจำนวนคงเหลืออัตโนมัติ
  • ยืนยันผู้ชนะ / สุ่มแทนคนที่ไม่อยู่ / ย้อนกลับ 1 ขั้น
  • ถ่วงน้ำหนักคนที่ยังไม่เคยได้รางวัล
  • seed ต่อรอบ แสดงบนจอเพื่อความโปร่งใส
  • โหมดเต็มจอสำหรับโปรเจกเตอร์ · เสียง/สั่น/คอนเฟตตี้
  • มุมมองลูกทัวร์เรียลไทม์ + export ใบเซ็นรับรางวัล

◷ ยังขาด — ต้องทำตอนลงโค้ดจริง

  • ตาราง draw_sessions / draw_prizes / draw_results + RLS — ตอนนี้ทุกอย่างอยู่ใน memory
  • Supabase Realtime ให้ลูกทัวร์เห็นผลพร้อมกันจริง (ตอนนี้จำลอง)
  • ยิงเข้า Broadcast อัตโนมัติเมื่อประกาศผู้ชนะ
  • ต่อ export เข้า DocumentHub + SignatureSheet ของจริง (ตอนนี้เปิดหน้าพิมพ์แยก)
  • ออฟไลน์: สุ่มฝั่ง client แล้ว sync ผ่าน offlineQueue.js
  • รูปรางวัล / รูปโปรไฟล์ผู้ชนะ (Supabase storage)
  • i18n — ต้นแบบนี้ฮาร์ดโค้ดภาษาไทยล้วน
  • สิทธิ์: ใครกดสุ่มได้บ้าง (permissions.js)
  • บันทึกกลุ่ม/คู่ที่สุ่มได้กลับเข้าทริป เช่น ตั้งเป็นทีมกิจกรรมถาวร
