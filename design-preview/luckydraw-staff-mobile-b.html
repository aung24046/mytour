แบบ B · แท็บล่าง + เมนูเกม

เปิดมาเจอหน้า เกม ก่อน แล้วเลือกเข้าบิงโกหรือสุ่มรายชื่อ · ปรับตามที่สั่งครบทั้ง 5 ข้อ กดใช้งานได้จริงทุกปุ่ม

เมนูเกม

รวมบิงโกกับสุ่มรายชื่อไว้ที่เดียว แต่ละการ์ดบอกสถานะสดว่ากำลังเล่นอยู่กี่ห้อง สุ่มไปแล้วกี่คน รางวัลเหลือเท่าไหร่ — สตาฟรู้ทันทีว่าอะไรค้างอยู่โดยไม่ต้องกดเข้าไปดู มีช่องเผื่อเกมใหม่ในอนาคตด้วย

ต้องแก้อะไรในโค้ดจริง

  • Dashboard.jsx — ในกลุ่ม duringTrip เปลี่ยนรายการ bingoHost เป็น { to:'/staff/games', key:'games', icon:'game' }
  • App.jsx — เพิ่ม route /staff/games และย้าย /staff/bingo-host ให้อยู่ใต้เมนูนี้ (ยังเข้าลิงก์ตรงได้เหมือนเดิม ไม่พังของเก่า)
  • Icon.jsx — เพิ่มไอคอน game
  • th.json / en.json — เพิ่มคีย์ games

ที่แก้ไป (ตามที่สั่ง)

  1. สุ่มกี่คน + รูปแบบการเฉลย ย้ายมาอยู่หน้าสุ่ม ใต้การ์ดสถานะ ปรับแล้วกดสุ่มได้ทันทีไม่ต้องสลับแท็บ
  2. ธีมจอใหญ่ เป็นดรอปดาวน์มุมบนขวา มีจุดสีนำหน้าให้เห็นว่าเลือกอันไหน ถัดมาเป็นปุ่มขยายเต็มจอ
  3. ห้องสุ่ม ย้ายไปแท็บตั้งค่า แต่ละห้องกด ✎ แก้ชื่อได้ ปุ่มลบย้ายเข้าไปอยู่ในโหมดแก้ไข
  4. ตัวกรอง เลือกได้ทีละอัน — ทั้งหมด / รถคัน 1 / รถคัน 2 / กลุ่มพิเศษ (กด ✎ เปลี่ยนชื่อได้ และติ๊กเลือกสมาชิกเองทั้งหมด)
  5. ปุ่มเปิดปิดรางวัล เป็นสวิตช์เลื่อน

สองเรื่องที่ขอแย้ง

ตัวกรอง "เช็คอินแล้ว" หายไป

พอเหลือ 4 ตัวเลือกแบบเลือกทีละอัน ตัวกรองเช็คอินก็หลุดไป ซึ่งเสี่ยง — สุ่มได้ชื่อคนที่ยังไม่ขึ้นรถแล้วประกาศหน้าเวที จะเสียจังหวะทันที ผมเลยแยกออกมาเป็นสวิตช์ "นับเฉพาะคนที่เช็คอินแล้ว" ไว้ใต้แถวตัวกรอง เปิดไว้เป็นค่าเริ่มต้น ทำงานร่วมกับตัวกรองได้ทุกอัน ถ้าไม่ชอบบอกได้ ผมถอดออกให้

ปุ่มลบที่ย้ายเข้าโหมดแก้ไข

ผมทำให้เหมือนกันหมดทั้งห้อง รางวัล และคนที่เพิ่มเอง ไม่ใช่แค่ห้อง เพราะถ้าห้องต้องกด ✎ ก่อนลบ แต่รางวัลลบได้เลยจากหน้าแรก มันจะจำยากและเสี่ยงกดพลาดตอนอยู่หน้างาน

ที่คงไว้เหมือนเดิม

  • แท็บสุ่ม / รายชื่อ / รางวัล / ประวัติ / ตั้งค่า
  • ยืนยันผู้ชนะ · ไม่อยู่แล้วสุ่มใหม่ · ย้อนกลับ · ล้างห้อง · ใบเซ็นรับรางวัล
  • สุ่มหลายคนบังคับใช้แบบคัดออกอัตโนมัติ
  • เพิ่มคนนอกระบบ และแก้ชื่อเล่นที่จะประกาศบนจอ
