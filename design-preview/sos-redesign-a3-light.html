คำตอบสั้น ๆ: พื้นขาวดีกว่าครับ เหตุผลหลักคือลูกทัวร์ใช้หน้านี้กลางแจ้ง จอมือถือกลางแดดจะหรี่และ UI เข้มจะอ่านแทบไม่ออก ส่วนจอสว่างยังพอสู้แดดได้ · แถมยัง reuse Card / Button / GuestNav เดิมได้ทั้งหมด ไม่ต้องเขียน dark variant ใหม่ · ยังคง "ความเป็นฉุกเฉิน" ได้ด้วยแถบหัวสีแดงบาง ๆ + ปุ่มแดงลูกใหญ่ ซึ่งเด่นบนพื้นขาวมากกว่าบนพื้นเข้มด้วยซ้ำ (ค่า contrast สูงกว่า)

สรุปเหตุผล

พื้นขาวชนะเรื่อง ใช้จริง

  • ใช้กลางแจ้ง/กลางแดด — จอมือถือกลางแดด UI เข้มจะจมหมด
  • ตัวเลขเบอร์โทรอ่านง่ายกว่าบนพื้นสว่าง
  • ต่อเนื่องกับหน้าอื่นในแอป ผู้ใช้ไม่สะดุด
  • reuse component เดิมได้หมด ไม่ต้อง maintain สองชุดสี
  • ปุ่มแดงบนพื้นขาว contrast สูงกว่าแดงบนพื้น teal เข้ม

พื้นเข้มชนะเรื่อง อารมณ์

  • สื่อว่า "เข้าโหมดฉุกเฉินแล้ว" ชัดกว่า
  • สบายตากว่าตอนกลางคืน
  • ดูพรีเมียม แตกต่างจากแอปทัวร์ทั่วไป

ทางที่แนะนำ

  • ใช้พื้นขาวเป็นค่าเริ่มต้น
  • คงแถบหัวแดงไว้ เพื่อบอกว่าเป็นโหมดฉุกเฉิน
  • ผูกพื้นเข้มเข้ากับ dark mode ของแอป (มี ColorModeToggle แล้ว) ได้ทั้งสองอย่างโดยไม่ต้องเลือก
